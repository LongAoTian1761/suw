# 国际宏观题库：正文翻译试点

当前范围仅为已公开答案的网页正文；不读取 PDF，不修改原文，也不回传姓名、
学号等表单字段。正文中自行填写的个人信息仍可能发送给翻译服务，所以实际启用
前应发布说明、确认服务的数据政策，并先在测试环境试跑。

1. 运行 `node --test scripts/translate-answers.test.mjs`。测试不联网。
2. 确认翻译服务、费用和数据处理政策后，在目标 Supabase 项目执行
   `answer-translations.sql`，并部署网页。旧项目没有迁移时，原文照常读取。
3. 在运行 Ollama 的电脑上配置 `SUPABASE_URL` 和 `SUPABASE_SERVICE_ROLE_KEY`。
   默认使用本机 `http://127.0.0.1:11434/api/chat` 和 `qwen3:4b-instruct`，
   不需要翻译 API 密钥。不要把数据库密钥放进仓库、网页或聊天。
4. 可先对测试项目用 `TRANSLATION_BATCH_SIZE=1` 执行
   `node scripts/translate-answers.mjs`。验收后用定时任务执行同一命令，
   禁止并发运行。默认每次最多五条；新公开答案和旧答案都会进入待翻译集合，
   不需要在浏览器打开时调用翻译服务。

试点只处理最多 1,200 字符的公开正文；长正文和 PDF 照常展示原文。
译文随原文版本读取；原文更新或撤回后，旧译文不会公开显示。任务失败时保留
原文，下轮可以重试；应监控退出状态。试点阶段如果某条持续失败，需要人工
排查，避免长期占用队列名额。停止定时任务即可停止新的外部翻译请求。
